# RV: Доедем до Route 65? — кооп-игра в браузере (Three.js + Cannon-es + PeerJS)

    npm install
    npm run dev        # локально
    npm run build      # статика в dist/ (base './')

Деплой на GitHub Pages: запушьте в `main`, в Settings → Pages выберите Source = GitHub Actions
(workflow уже в `.github/workflows/deploy.yml`).

Мультиплеер: хост создаёт комнату и получает 5-символьный ID, остальные (до 4 игроков) вводят его.
Хост — авторитетный сервер физики, снимки состояния рассылаются ~20 раз/с. Используется публичный брокер PeerJS.

Файлы: main.js (цикл, рендер, лобби) · network.js · physics.js (чанки хайтфилдов, статика) · world.js (террейн, биомы, препятствия)
· rv.js (RaycastVehicle, повреждения, лебёдки, меш) · player.js (игрок, ввод, аватар) · host.js (вся игровая логика)
· view.js (отрисовка снимка) · items.js · bears.js · ui.js.

Новое: обставленный интерьер (кухня, холодильник, диван, кровать, кабина), топливо, смена дня и ночи, дождь в болоте, растительность, лагерь, шоссе, прогресс маршрута.

Все механики оригинала перенесены: трамплины, камеры заднего вида и зеркала, бросок крюка (Q), трос на игрока (страховка), тарзанка,
корпус/двигатель/шины (металлолом, масло, запаска, инструменты), змеи и яд (противоядие), лава, водоёмы, камнепады, боевой вертолёт,
могилы на АЗС, кофе/сигареты (ускорение), пространственный голосовой чат (M), 71 кассета с магнитофоном, 6 шляп и шкаф для переодевания,
гольф у лагеря, 96 достижений (J). Расхода топлива нет.
